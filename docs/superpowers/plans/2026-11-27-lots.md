# Lots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stage 6: every zoned block divided into lots (plus open ground in deep blocks), each lot
recording the road category along each side.

**Architecture:** Pure modules in `src/stages/lots/`: `rules.ts` (target sizes), `cut.ts`
(street-aware recursive splitting with straight half-plane cuts), `faces.ts` (per-edge
categories), `stage.ts`. Tinted renderer. The blocks stage's provisional `MIN_LOT` gives way to
the lots table.

**Tech Stack:** TypeScript 7, Vitest, clipper2-ts via `grammar/clipper.ts`.

**Spec:** `docs/superpowers/specs/2026-11-27-lots-design.md`

## Global Constraints

- Targets at step 9 (frontage × depth, m): LR 12×24; LC, LO 20×30; HR HC HO HCR HCO 7×20;
  MR MCR 25×30; UR UCR 30×30; big-lot MC MO UO UCO UCOR 160×70 (the blocks' densest defaults:
  another stage's settings aren't visible). Scaled by `lotFactor(step)` on both sides and by the
  `lotSize` setting (0.5–2, default 1).
- Cut while frontage run > 1.4 f; spine cut while depth > 2 × 1.4 d; open ground when block depth
  (`rectWidth`) > 4 d (inset by 2 d), unless the inset is under one target lot.
- Accept: both sides keep an allowed face (≥ 0.5 f of allowed run), area ≥ 0.5 f d, box short side
  ≥ 0.5 min(f, d); final sides fill ≥ min(0.7, 0.9 × parent fill).
- Edge codes: `A` `C` `L` road, `o` open, `-` another lot. Attrs on lots: `faces`, `edges`, `front`.
- Stage id `lots`, title `Lots`, after `blocks`. Children `lot:n`, `open:0`. Site data `lotStats`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A block whose only allowed road is short (a corner): it stays one lot rather than producing a
  lot without allowed frontage. Task 2 test.
- A big-lot block (UO) of ordinary size: one lot. Task 2 test.
- Odd-shaped (L-shaped) blocks: half-plane cuts that would slice it into 3+ parts are refused.
  Task 2 test.
- Partition per block holds (lots + open ground). Task 4 test.
- Stage time at 10 km acceptable (measure; target < 10 s). Task 4.

### Task 2: Cutting (`lots/cut.ts`)

**Produces:**
```ts
interface LotCtx { target: { frontage: number; depth: number }; allowed: (p: Point2) => boolean /* outline point on an allowed road */ }
cutBlock(block: MultiPolygon, ctx: LotCtx): { lots: MultiPolygon[]; open: MultiPolygon | null; refused: number }
```
Straight cuts as half-planes (a large rectangle on one side of the line, intersected and
differenced): exact partition; refused unless it yields exactly one polygon each side. Frontage
runs from outline samples every 2 m tested by `allowed`. Candidate positions like blocks' `plans`
(whole numbers of targets, offsets 0, ±0.1, ±0.2), direction the run's inward normal at the cut
point (square to the street). Spine: along the box's long axis through the centre.

- [ ] Tests (rectangles with `allowed` = point on chosen sides):
  - 100 × 50 block, roads on both long sides, LR at step 9 (12×24): two rows (spine), each cut into
    ~8 lots; every lot touches an allowed side; lots partition the block;
  - 200 × 50 block, road on one long side only, H (7×20): one row of ~28 lots, no spine cut (both
    halves would need frontage);
  - 300 × 300 block, roads all round, LR (12×24): open ground present, every lot ≤ 2 × 24 + slack deep;
  - 150 × 70 UO block: one lot;
  - L-shaped block: no lot is a multi-polygon; partition holds.
- [ ] Implement; pass; commit.
